# LicenceFlow Plain-Language Copy Audit

## Goal

Keep LicenceFlow formal, trustworthy and professional, but make the language comfortable for ordinary Indian citizens who can read English but may not be comfortable with technical or high-level English.

Target style:

- English: clear Indian English, roughly Class 7–9 reading comfort.
- Hindi: simple, professional, everyday Hindi used in consumer/government apps.
- One idea per sentence.
- Prefer short verbs and familiar words.
- Keep official terms when they are necessary: Learner's Licence, Driving Licence, Aadhaar e-KYC, OTP, RTO, Form 1, application number, payment status.
- Do not simplify by removing important safety, privacy or prototype disclosures.

---

# 1. Global writing rules

## Prefer these words

| Avoid / reduce | Prefer |
|---|---|
| citizen | you / applicant, depending on context |
| synthetic | demo / sample, except in formal prototype disclosure |
| prototype | demo, except in the legal/honesty disclosure |
| compatibility | device check / works on this device |
| readiness | device check / ready for the test |
| rehearsal | practice |
| recovery rehearsal | save-and-resume practice / recovery practice |
| prerequisite | required step |
| route | option / method |
| identity route | identity method |
| establish a session | start |
| stream health | camera/mic working |
| checkpoint | saved answer / save point |
| checkpointing | saving answers |
| secure context | secure page / secure connection |
| browser observations | browser checks |
| responsive movement observed | head movement detected |
| current transaction state | payment status |
| reconciliation | payment check |
| gateway | payment page, except in developer/test controls |
| authorization | payment approval / payment result |
| integrity observation | test-condition note |
| presentation attack | fake photo/video attempt, only if citizen-facing explanation is needed |
| authoritative material | official material |
| configured prototype amount | demo amount |
| direct-to-citizen | online service, unless the official term matters |
| contactless | online / without visiting the RTO, if that claim is verified |
| faceless | online / no office visit, if verified |
| secured online test | online test |
| knowledge-test simulation | demo test |
| fictional information | demo details |
| fictional profile | sample profile |
| applicant intends to learn | vehicle you want to learn to drive |

## Buttons

Use short verb-first labels:

- Start application
- Continue application
- Check status
- Start device check
- Check again
- Continue to practice
- Review fee
- Pay now
- Check payment
- Start test
- Save answer & next
- Resume test
- View result
- Download licence
- Back

Avoid long button labels unless the safety meaning would be lost.

# 2. Hindi writing rules

Use simple modern Hindi. It is okay to keep familiar English technical words in Devanagari.

## Prefer

- डिवाइस जाँच
- ऑनलाइन टेस्ट
- कैमरा
- माइक्रोफोन / माइक
- ब्राउज़र
- पेमेंट / भुगतान
- स्टेटस / स्थिति
- डेमो
- OTP / ओटीपी
- e-KYC / ई-केवाईसी
- सेव / सहेजा
- दोबारा शुरू करें
- इंटरनेट कनेक्शन

## Avoid where possible

| Hard / formal Hindi | Simpler Hindi |
|---|---|
| अनुकूलता | डिवाइस जाँच / यह डिवाइस टेस्ट चला सकता है |
| प्राधिकरण | भुगतान स्वीकार हुआ / भुगतान मंजूर हुआ |
| प्रतिक्रियाशील गतिविधि | सिर की हलचल मिली |
| विन्यास योग्य | डेमो |
| प्रामाणिक | आधिकारिक |
| पुनर्प्राप्ति / रिकवरी (when a plain phrase works) | फिर से शुरू करना / सहेजी जगह से जारी रखना |
| पहचान प्रमाणीकरण | पहचान की जाँच |
| परिदृश्य | डेमो स्थिति / उदाहरण |
| वर्तमान लेन-देन स्थिति | भुगतान की स्थिति |
| संगतता / compatibility | डिवाइस जाँच |
| सुरक्षित संदर्भ | सुरक्षित पेज |
| अवलोकन | जाँच / संकेत |
| अधिसूचना (for ordinary UI) | सूचना / अपडेट |
| अनुपालन | नियमों का पालन |

Use "आप" in helper text. Keep "आवेदक" mainly for formal field names.
